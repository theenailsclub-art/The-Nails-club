Categories

Edit category names, taglines, and cover photos shown across the site

How it works: These are the categories customers filter by on the homepage and collection page. Editing a name, tagline, or cover photo here updates it everywhere on the live site — no code changes needed. The internal key used to link products to a category can't be changed after a category is created, to avoid breaking existing products.

How it works: Reels you add here appear in the "In Motion" strip on the homepage. Upload a video file (MP4) and a poster image (shown before the video plays). Changes go live as soon as you save.
